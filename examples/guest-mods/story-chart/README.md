# story-chart

A story mod's chart: when the mod is on, Link gets the storyteller's chart in the loaded save
file, and it marks Windfall Island (square D2) on his sea chart. Open the MAP screen: the island
carries the white ring the game itself puts on the next story island. The save file remembers
the chart; save the game to keep it.

It shows `wwhd_chart_give` and `wwhd_chart_mark` from
[docs/mod-sdk-v2.md](../../../docs/mod-sdk-v2.md#charts-and-markers).
