# rito-letter

The smallest story mod: when it is on, a letter waits in the Rito postbox of the loaded save
file. Check any postbox: it hands the letter out the way it hands out the game's own mail, and
the game shows it in its letter window. The save file remembers the letter, so each file gets it
once; save the game after reading it.

It shows `wwhd_mail_send` from [docs/mod-sdk-v2.md](../../../docs/mod-sdk-v2.md#letters). The
text is original to this example.
